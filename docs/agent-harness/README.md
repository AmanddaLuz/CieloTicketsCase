or behavior change. Do not duplicate specs, paste routine command output or
store secrets.

Each entry should contain:

```text

Scope:
Input constraint:
Decision:
Validation:
Canonical docs updated:
```

Registros:

- `2026-08-28-foundation.md`: decisões incrementais das fases;
- `final-delivery.md`: prompts representativos, restrições e resultados finais.
